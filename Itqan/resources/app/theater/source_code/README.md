## 🌟 المزايا الرئيسية

### 1. 📊 لوحة تحكم إدارية فاخرة (Admin Dashboard)
- **إحصائيات حية**: إجمالي الطاقة الاستيعابية، المقاعد المحجوزة، ونسبة الحضور الفعلي.
- **معدلات الإشغال**: نسب مفصلة للدور الأرضي، البلكونة العلوية، ومقاعد كبار الشخصيات (VIP).
- **بث مباشر للحضور**: شريط حي يعرض أسماء الضيوف وأرقام مقاعدهم فور مسح الباركود عند الباب.

### 2. 🗺️ خريطة المسرح التفاعلية (Interactive Seating Map)
- خريطة بصرية تفاعلية كاملة للمسرح (الدور الأرضي + الدور الثاني / البلكونة).
- تمييز حالات المقاعد: **شاغر / متاح** 🟢، **محجوز** 🟡، **تم الدخول** 🟣، **VIP** 👑.
- حجز فوري للمقاعد مع إمكانية تعديل بيانات الضيف، فئة المقعد، وإلغاء الحجز.

### 3. 🎫 بطاقات الحضور والدعوات الإلكترونية (Smart QR Tickets)
- تصميم بطاقة حضور عمودية ذكية وفاخرة تحاكي تصميم الهواتف الحديثة مع شعار وزارة التعليم.
- **رمز QR ديناميكي**: عند مسحه بالهاتف يفتح صفحة تفاعلية للضيف توضح موقعه في المسرح فوراً.
- تصدير ومشاركة التذكرة كصورة عالية الدقة PNG أو إرسالها مباشرة عبر الواتساب.

### 4. 👥 إدارة الضيوف واستيراد وتصدير Excel / PDF
- **تصدير كشف Excel (`.xlsx`)**: يشمل كافة بيانات الحضور والمقاعد وروابط التذاكر.
- **استيراد ملفات Excel**: قراءة قوائم المدعوين وتوزيعهم آلياً وذكياً على المقاعد المتاحة.
- طباعة كشوفات منظمة ومصنفة حسب الصفوف والأدوار.

### 5. 📷 ماسح الباركود عند الباب (Live Gate Scanner)
- مسح فوري عبر كاميرا الجهاز أو قارئات الباركود الليزرية (USB Barcode Gun).
- تنبيهات صوتية ذكية (Web Audio API): نغمة ترحيبية للدخول الصحيح ونغمة تحذير للتذاكر المكررة.
- عرض فوري لاسم الضيف وموقعه (الصف، المقعد، القطاع، المدخل).

### 6. 🔐 حماية وأمان لوحة التحكم
- شاشة تسجيل دخول مخصصة باسم مستخدم وكلمة مرور (الافتراضي: `admin` / `admin123`).
- إمكانية تعديل بيانات الدخول وتصدير نسخ احتياطية كاملة من قاعدة البيانات.

## 🚀 طريقة التشغيل

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).

### 1. استنساخ المستودع (Clone Repository)
```bash
git clone https://github.com/your-username/theater-seat-manager.git
cd theater-seat-manager
```

### 2. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### 3. تشغيل خادم التطوير المحلي (Run Dev Server)
```bash
npm run dev
```

افتح المتصفح على الرابط:
- **لوحة التحكم:** `http://localhost:3000/`
- **بوابة المستفيد والضيوف:** `http://localhost:3000/beneficiary.html`

> 💡 **ملاحظة للوصول عبر الجوال والشبكة المحلية:** السيرفر يعمل تلقائياً بوضع `--host`، يمكنك مسح الـ QR أو فتح الرابط باستخدام عنوان IP جهازك (مثال: `http://192.168.1.4:3000/`).

## 📦 البناء والتصدير
