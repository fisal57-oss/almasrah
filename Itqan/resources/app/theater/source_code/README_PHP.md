# دليل تشغيل ورفع نظام حجز مقاعد المسرح وبوابة المستفيد (PHP & MySQL)

تم تحويل النظام بالكامل إلى **PHP** مع قاعدة بيانات **MySQL (SQL)** ليعمل على أي استضافة ويب مباشرة (cPanel، سيرفرات خاصة، XAMPP، WampServer، أو خوادم سحابية).

---

## 📁 هيكل ملفات الـ PHP و SQL في المشروع

| الملف / المجلد | الوصف والدور |
| :--- | :--- |
| **`schema.sql`** | مخطط قاعدة البيانات الكامل (الجداول، المفاتيح، الفهارس). |
| **`config.php`** | إعدادات الاتصال بقاعدة البيانات PDO والدوال المساعدة المشتركة. |
| **`install.php`** | **مثبّت تلقائي بنقرة واحدة** ينشئ الجداول ويدخل كافة المقاعد الـ 746 وحجوزات تجريبية. |
| **`beneficiary.php`** | **صفحة المستفيد والضيوف المستقلة** بالكامل (البحث، التذكرة، باركود QR، خريطة المسرح، والحجز الذاتي). |
| **`index.php`** | **لوحة التحكم الإدارية** للمسرح (إدارة المقاعد، الحجوزات، مسح التذاكر بالبوابة، والإعدادات). |
| **`api/`** | مجلد واجهات الـ REST API (استعلام وحجز وإلغاء ومسح تذاكر بصيغة JSON). |

---

## 🚀 طريقة التثبيت والرفع على استضافة الويب (cPanel / Server)

### الخطوة 1: رفع الملفات
1. قم بضغط ورفع ملفات المشروع التالية إلى مجلد موقعك (مثلاً `public_html` أو مجلد فرعي مثل `public_html/theater/`):
   - `beneficiary.php`
   - `index.php`
   - `config.php`
   - `install.php`
   - `schema.sql`
   - مجلد `api/` بالكامل.

### الخطوة 2: إعداد قاعدة البيانات في الاستضافة
1. من لوحة تحكم الاستضافة (cPanel)، ادخل إلى **MySQL Databases** وأنشئ قاعدة بيانات جديدة واسم مستخدم وكلمة مرور، وامنحه كافة الصلاحيات (ALL PRIVILEGES).
2. افتح ملف **`config.php`** وعدّل السطور التالية ببياناتك الجديدة:
   ```php
   define('DB_HOST', 'localhost');
   define('DB_NAME', 'اسم_قاعدة_البيانات');
   define('DB_USER', 'اسم_المستخدم');
   define('DB_PASS', 'كلمة_المرور');
   ```

### الخطوة 3: التهيئة بنقرة واحدة (One-Click Install)
1. افتح متصفحك وادخل على رابط المثبّت:
   ```text
   https://your-domain.com/install.php
   ```
2. سيقوم المثبّت تلقائياً بإنشاء الجداول وإدخال كافة مقاعد المسرح (746 مقعداً) فوراً!

---

## 💻 طريقة التشغيل المحلي (XAMPP / WampServer)
1. انسخ مجلد المشروع إلى داخل مجلد `C:\xampp\htdocs\theater`.
2. شغّل خدمتي **Apache** و **MySQL** من برنامج XAMPP Control Panel.
3. افتح المتصفح على:
   - للتهيئة التلقائية: `http://localhost/theater/install.php`
   - بوابة المستفيد المستقلة: `http://localhost/theater/beneficiary.php`
   - لوحة الإدارة: `http://localhost/theater/index.php`

---

## 🌟 مميزات النسخة المحولة:
1. **لا تتطلب خوادم بايثون أو Node.js:** تعمل على أي خادم PHP 7.4 أو PHP 8.x قياسي.
2. **قاعدة بيانات علائقية SQL متكاملة:** سرعة فائقة في الاستعلام وفهارس دقيقة للحجوزات والرموز.
3. **أمان تام لصفحة المستفيد:** خالية من أي أدوات إدارية وقابلة للمشاركة مباشرة للجمهور عبر الرابط أو رمز الـ QR.
4. **دعم التنزيل والطباعة:** توليد بطاقات الـ QR Code وتحميلها كصورة بدقة عالية أو طباعتها مباشرة.
